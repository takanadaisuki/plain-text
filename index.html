文字変換の仕組み

入力したひらがなをローマ字に変換し、ローマ字を1文字ずつ逆順に並べ替えます。その並びから、ひらがなとして読める部分を変換して表示します。

通常のローマ字表記とは一部異なる、逆再生セリフ用の独自表記を使用しています。

し → si ／ ち → ti ／ つ → tu ／ ふ → hu
しゃ → sya ／ ちゃ → tya ／ じゃ → ja ／ じょ → jo

※この処理は文字の変換規則として確定していますが、変換した音が実際の逆再生音声と必ず一致するという意味ではありません。

変換例

あいす → aisu → usia → うしあ

「あいす」を「aisu」と表し、1文字ずつ逆順にすると「usia」です。これを「u・si・a」に区切って「うしあ」と表示します。

あさって → asatte → ettasa → えったさ

逆順で同じ子音が続き、後ろの音と組み合わせて読める場合は、小さい「っ」に変換します。

現時点で確認できていること

① 文字を逆順にすることと、音声を逆再生することは違う

音声の逆再生は、録音した波形の時間順序を反転する処理です。一方、文字変換はローマ字の並びを逆順にする処理です。両者は一致するとは限りません。

ルール：文字変換は発音の目安とし、最後は録音して逆再生した音で確認する。

② 日本語の音は前後の音の影響を受ける

音声学では、隣り合う音の調音が重なり合う「調音結合」が知られています。例えば「ん」の調音位置は後続する子音によって変わります。

さんぽ：後ろの「ぽ」に向けて唇を閉じる発音になりやすい
さんた：後ろの「た」に向けて舌先を使う発音になりやすい

ルール：「ん」を含む音は前後の音も考慮する。ただし現行の自動変換には未反映。

③ 母音は常にはっきり発音されるとは限らない

日本語では「す」「し」などの母音 /u/・/i/ が、周囲の無声子音などの条件によって無声化することがあります。

「です」「すき」など：/u/ が弱くなったり無声化したりする場合がある

ルール：文字にある母音が録音でも明瞭とは限らない。自動で母音を消す処理はまだ行わない。

④ 過去の検証で比較的一貫している聞こえ方

これまでの報告では、次の語について複数回、同じ聞こえ方が記録されています。

ぱんつ → ぱんつ
ぽけもん → ぽけもん
がりがり → がりがり
ぽらぽら → ぷぉらぽら

これらはこれまでの回答が一致しているという観察記録であり、すべての人や録音条件で成立する普遍的な法則ではありません。現行の文字変換には一律の「ぷぉ」「ぐぁ」補正を加えません。

注意事項と変換ルール

① 文字と実際の発音の違い

入力されたひらがなを文字どおりに変換します。例えば「こんにちは」は「konnitiha」となりますが、実際の最後の音は通常「わ」です。

こんにちは → konnitiha
発音に寄せて入力する場合：こんにちわ

ルール：文字と発音が違う場合は、実際に読みたいひらがなで入力する。

② 「ん」の扱い

「ん」は文字変換では「n」にします。「n」が連続すると、音の区切りが分かりにくくなる場合があります。

あんない → annai

ルール：「ん」は現行では n として処理する。実際の音の違いは録音で確認する。

③ 表記できない文字

逆順ローマ字には、母音を伴わない子音など、ひらがなで正確に表せない文字が現れます。変換できない部分だけを赤字で残します。

ルール：読めない文字があっても、後ろの読める部分の変換は続ける。

④ 長音「ー」

長音は「-」として残し、逆順にするとその位置も反転します。

こーら → ko-ra → ar-ok

ルール：「ー」は勝手に削除せず、逆順の「-」として残す。

⑤ 小さい「っ」

小さい「っ」は、次の子音を重ねて表します。逆順で子音が重なり、読める場合は「っ」に戻します。

あさって → asatte → ettasa → えったさ
tta → った ／ kka → っか ／ ssa → っさ ／ ppa → っぱ

ルール：読める子音の重なりは小さい「っ」にする。

⑥ 特殊な逆順の読み方

逆順になったローマ字の一部には、サイト独自の読み方を割り当てています。

おきゅう → okyuu → uuyko → ううきょ
yka → きゃ　yku → きゅ　yko → きょ
ysa → しゃ　ysu → しゅ　yso → しょ
yta → ちゃ　ytu → ちゅ　yto → ちょ
yna → にゃ　ynu → にゅ　yno → にょ
yha → ひゃ　yhu → ひゅ　yho → ひょ
yma → みゃ　ymu → みゅ　ymo → みょ
yra → りゃ　yru → りゅ　yro → りょ
yga → ぎゃ　ygu → ぎゅ　ygo → ぎょ
yba → びゃ　ybu → びゅ　ybo → びょ
ypa → ぴゃ　ypu → ぴゅ　ypo → ぴょ
yi → い　wi → うぃ　wu → う　we → うぇ　wo → うぉ

ルール：これらは逆再生用の独自の文字変換であり、音声学的に常に同じ音になることを保証しません。

⑦ 単独子音の発音補助

逆順ローマ字で子音だけが残った場合、発音しやすくするために補助的な母音を付けることがあります。

k → く　s → す　n → ん　h → ふ　m → む
r → る　g → ぐ　z → ず　b → ぶ　p → ぷ
さいせ → saise → esias → えしあす
かいけい → kaikei → iekiak → いえきあく

「t」「d」「y」「w」など、一意に決めにくい子音は表記不可のまま残す場合があります。

ルール：単独子音の補助は発音の目安であり、元の子音と完全に同じ音ではない。

重要：現在の文字変換は、実際の逆再生音声を自動認識しているわけではありません。文字の逆順と読み方の補助を行うツールです。最終的な聞こえ方は、録音して確かめてください。

📝 次回制作予定

以下は研究結果や検証中の仮説を参考にした今後の検証・実装候補です。今回の確定ルールには含めていません。

  • 「ぽ→ぷぉ」「が→ぐぁ」「ぱ→ぷぁ」の条件：「がらす」「がりべん」「ぽろぽろ」などは検証回によって回答が変わっており、固定ルールにはできません。
  • 母音の無声化を反映する処理：「す」「し」の母音を、どの条件で省略・短縮するかを調べます。
  • 語尾の子音・短い音：単独の t・d・y・w などを省くか、短い補助音にするかを検証します。
  • 「ん」の前後関係：後続子音による音の変化を逆読みへどう反映するかを調べます。
  • 促音・破裂音・摩擦音：時間反転で音がどう聞こえるかを比較します。
  • 発音速度・アクセント・再現性：同じ言葉でも録音ごとに結果が変わる原因を調べます。
  • 変換候補の複数表示：十分な検証結果が集まった場合に、確信度とともに複数の読み方を提案する方法を検討します。

検証は1回最大10問とし、判断できない場合は無理に二択にしません。結果が蓄積してから実装を判断します。
